Privacy policy

This policy describes how Mohamed Hagras operates Hermes Default Gmail for his own personal email assistance.

Information accessed

With Google authorization, the application can access the account’s email address, message headers, message bodies, labels and attachment metadata. It can prepare and manage drafts, including files the owner selects. The granted Gmail compose permission also allows sending messages.

Use of information

Information is used to carry out the owner’s requested email tasks, provide relevant responses, prepare documents or drafts, and preserve task progress. Email content is treated as source data, not permission to perform additional actions.

Processing and sharing

Google processes Gmail API requests and retains mailbox content under its own policies. Relevant message content and instructions can be sent to the AI provider configured by the owner to perform the requested task. Results requested through Telegram can be sent to Telegram. Provider processing, retention and account settings apply to those services; this application does not promise that all processing stays on the owner’s computer.

The operator does not sell Google user data or use it for advertising or general-purpose AI model training. The operator must use service configurations consistent with these limits. Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and retention

Authorization credentials are stored in restricted local files on the owner’s computer. Local conversation history, task records, prepared message content and draft identifiers can remain until the owner removes them. No automatic deletion period is currently configured. Gmail drafts remain in Gmail until managed there. The public information website does not receive mailbox credentials or email content.

Control and removal

The owner can revoke the application’s access in Google Account connections. Revocation prevents future authorized API access but does not automatically erase existing Gmail drafts, local history or data already processed by other services. Local records and provider-held data must be managed separately. Contact the operator for questions or removal requests.

This information website

The pages contain no analytics scripts, advertisements, account forms or cookies set by the site’s code. If hosted on GitHub Pages, GitHub may log visitors’ IP addresses for security under the GitHub Privacy Statement.
